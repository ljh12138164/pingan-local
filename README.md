# 平安手札

2026-11-08 新增速度资产统计、统计图分享与雷达主属性多选。实现范围和验证限制见 [beta.42 功能对照增量](UPDATE-beta42.md)；本轮尚未生成新版 Windows EXE。

独立实现的 Windows 本地《阴阳师》数据工作台。Tauri 2 + React + TypeScript + Rust + SQLite。无需应用账号或会员，所有已实现功能直接使用。当前为 **0.4.0 版本**。

## 启动

最新增量包为 `releases/20261030-preview/平安手札-0.4.0-20261030.exe`，包含虚拟兑换、临时背包和批量强化，以及此前已实现功能。附 SHA256 和范围说明。需要 Windows 10/11 x64 及 WebView2。当前为预览版，整款软件尚未完成，旧包保留。

首次启动为空档案。进入「数据读取」，选择以下方式之一：

- 独立桌面读取：游戏登录后刷新进程，选择 `onmyoji.exe`，读取当前角色。已在本机 Windows x64 / Python 3.11.6 客户端验证。客户端更新可能需要适配内存结构。读取错误时保留旧档案。
- MuMu 模拟器：设置中开启 root 并重启，登录游戏；填写 MuMu 安装目录，扫描实例，检查权限与游戏，再读取角色。扫描通过 MuMu 自带实例信息发现已启动的本机端口，ADB 连接中断后会重连。已验证 MuMu 15.0 实例中的 x86_64 / Python 3.11.6 客户端；2026-10-28 完整读取 6,466 枚御魂和 2,273 条式神记录，约 38 秒。读取期间保持庭院界面。应用通过本机 ADB 服务与独立组件只读访问游戏内存。
- 藏宝阁：粘贴网易公开商品链接，预检后保存为独立本地档案。
- JSON：下载模板、预检后导入本项目格式。可导出本地档案并再次导入。
- 演示档案：主动创建，内容为合成数据，界面持续标明演示状态。

数据库位于 `%LOCALAPPDATA%\PinganLocal\data.sqlite3`。再次读取同一角色会更新其档案，并保留本地手动任务、成员名册、手动资源与手动添加式神。读取前后自动建立快照。建议在「角色档案」保存快照，或导出 JSON 备份。

现有页面覆盖工作台、读取、档案、角色分析、任务、御魂分析、一速、面板配装、头尾、雷达、模拟强化、评分标准、式神录、碎片、结界卡库存、外观清单、资产、寮管理、百科 / 悬赏、御魂掉落表、阵容资料、绘卷助手、小工具及设置。各页实现范围和缺失项见功能矩阵。

御魂支持筛选、评分、明细、CSV、Excel和PNG / ZIP分享长图。配装支持六号位、任意套装件数配方、主属性多选、面板上下限与指标目标值；单件替换建议显示面板增益。一速在界面注明的条件内使用精确动态规划，其余大型库存搜索会明确标为近似。角色面板支持觉醒附加属性、首领御魂固有属性、六件同套时两次两件套属性，以及另外触发一次的六件套固定属性；8 种新套装来自独立游戏配置。四件套触发与技能伤害仍未建模。

御魂雷达按套装或六个号位查看，评分与库存共用所选评分标准和 PVE / PVP 场景。未知评分保留未知，已知零分参与平均；支持查询、满级筛选、排序、图表与表格、CSV。

任务区分别展示采集事实和本地待办；本地日常/每周勾选按日期重置。碎片区区分普通、绑定碎片和契约书，展示传记任务进度。结界卡页面显示普通与折叠库存、每小时及单卡产出，并按真实开始时间和时长显示自己的卡片及寄养倒计时。寮管理读取全体成员功勋、捐赠、活跃、入寮与离线记录。先在游戏中打开相应页面载入缓存，再在应用中刷新；可选择每 15 秒刷新。缺失字段保留未知，缓存在线状态标注为读取时状态。

工作台允许编辑 HTML/CSS/JavaScript 组件，组件运行于限制网络和父页面访问的沙箱，仅接收本地摘要。

## 开发

需要 Node.js、Rust MSVC 工具链、Visual Studio C++ Build Tools 及 WebView2。

```powershell
npm ci
npm run dev
npm test
npm run build
npm run desktop:build
```

开发 UI 为 `127.0.0.1:47820`，开发 Rust API 为 `127.0.0.1:47821`。两者由 `npm run dev` 启动；正式桌面版通过 Tauri IPC 调用 Rust，不需要开发服务。可用 `PINGAN_DB_PATH` 环境变量为开发服务指定测试数据库，桌面版仍使用标准数据库路径。

主要代码：`src/` 界面；`src-tauri/src/store.rs` SQLite/操作入口；`game_memory.rs` 进程只读采集；`emulator.rs` ADB 发现、权限诊断和二进制传输；`reader/memory.c` 独立 Android 只读组件；`game_codec.rs` 二进制配置解码；`game_convert.rs` 数据转换；`engine.rs` 面板/配装；`upgrade.rs` 强化参考；`cbg.rs` 公开商品转换；`realm.rs` 结界、寄养与成员归一化；`game_windows.rs` 游戏窗口管理。

源码附带本项目编译的 Android x86_64 组件，可直接编译桌面应用。修改组件后，安装 Zig 并运行 `powershell -File scripts/build-android-reader.ps1 -Zig <zig.exe 路径>` 重新生成；本次使用 Zig 0.15.2。musl 许可见 `src-tauri/reader/MUSL-COPYRIGHT`。

常规 Rust 测试不依赖游戏。当前 58 项通过，9 个依赖真实进程或单独样本的测试默认忽略；其中 MuMu 完整读取另行实测通过。源码包不附带私人库存或数据库。
